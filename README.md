### Hand Cricket Server

This is your favorite school time game handcricket, implemented in Expressjs using websockets.

Create rooms and play with your friend in Realtime!

> Note: This is just the server, you can deploy this server and create your own client side application. All the 'Events' are listed below.

### Event list

| Event Name |                        Function                         | Scope  |
| ---------- | :-----------------------------------------------------: | :----: |
| JOIN_ROOM  | Join a room by specifying the room id and the player id | Client |
